Télécharger TacticalWar-client.zip

  1. Télécharger le fichier zip ci-dessus.
  2. Dézipper : clic droit sur le fichier, Extraire tout…, puis choisir un dossier (par exemple Documents). Ne pas lancer le jeu depuis l'intérieur du zip.
  3. Lancer TacticalWar.exe dans le dossier extrait. L'adresse du serveur est déjà remplie : il reste à saisir l'identifiant et le mot de passe de la fiche de l'équipe.

Le message « ne correspond pas au serveur » revient ? Fermer l'ancien jeu, supprimer son dossier, puis recommencer avec le nouveau zip.

Les règles et les classes sont expliquées dans le guide du joueur.
